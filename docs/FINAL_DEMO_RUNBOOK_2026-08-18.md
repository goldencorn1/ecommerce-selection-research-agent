# 选品研判台：最终现场演示手册

版本：Final V1.0
建议时长：5 分钟
推荐品类：可折叠露营桌
演示模式：Mock 离线 + 内置 Demo 商品 API

## 1. 演示前准备

### 启动

项目根目录双击：

```text
start_ecommerce_mock.bat
```

打开：

```text
http://127.0.0.1:3000/ecommerce
```

本路径不需要真实 AI Key、Tavily Key 或商品 API Key。

### 现场检查

- 页面能打开；
- 能看到“Mock 离线”；
- backend healthy；
- 页面没有红色错误提示；
- 默认品类为“可折叠露营桌”。

## 2. 五分钟演示路径

### 0:00—0:40 介绍产品

演示话术：

> 这是一个电商选品研究工作台。它不直接告诉我们“买什么”，而是把研究拆成证据、评分、风险和验证动作，回答“下一步先验证什么”。

指出顶部的演示边界：Mock 和候选证据不会自动变成商业事实。

### 0:40—1:30 展示配置能力

1. 展示品类、市场、价格范围；
2. 展示 Mock/Live 选择；
3. 展示模型和搜索供应商配置；
4. 进入“用户商品 API”区域；
5. 选择“本地 Demo 商品 API”；
6. 勾选“已启用”。

话术：

> 真实商品 API 由使用者自行配置；由于当前没有真实商业数据，我们用项目内置的固定 Demo API 演示同一条配置和预检链路。

### 1:30—2:10 演示商品 API 预检

1. 点击“预检并读取样品”；
2. 展示 3 条样品和字段映射；
3. 点击“载入本次研究”。

强调：

> 这些样品标记为 DEMO_ONLY，只用于演示连接、映射和数据进入研究的过程，不代表真实商品事实。

### 2:10—3:00 生成报告

点击“一键体验 Mock”，展示：

- 研究过程和 Agent 状态；
- 参数校验、搜索、整理、报告生成进度；
- 推荐方向和平均评分。

### 3:00—4:10 讲解报告

按页面导航顺序点击：

1. **摘要**：当前判断、平均分和总体结论；
2. **证据**：候选证据、来源和证据边界；
3. **风险**：质量门禁、阻断原因和商业核验状态；
4. **行动**：验证动作、成功阈值、需补数据和失败处理。

补充展示：

- 推荐方向得分趋势图；
- 价格分布图；
- 评分组成和验证卡片。

### 4:10—5:00 展示可交付性

展示以下任意两项：

- Excel/CSV 预览、字段映射和校验；
- 历史报告回放；
- 多报告对比；
- JSON、Markdown、HTML 导出。

收尾话术：

> 当前版本已经完成可运行 Web Demo 验收。真实商业 AI 和真实商品数据不是本次 Demo 的前置条件；后续只需由使用者配置有授权的模型、搜索或商品数据服务。

## 3. 无真实 AI 时的标准口径

请统一使用以下表达：

- “当前使用结构化 Mock，外部请求数为 0。”
- “Demo 商品 API 是本地固定样品，不是真实商业数据。”
- “DeepSeek 可作为用户自配的模型入口，但本次不依赖它。”
- “真实商品信息需要用户提供合法授权 API、Reader 服务或 Excel/CSV 文件。”
- “报告用于确定验证优先级，不直接支持采购或放量。”

避免使用：

- “系统已经抓到了真实销量”；
- “这个商品一定能卖”；
- “AI 已经验证了利润”；
- “Demo 样品代表市场真实价格”。

## 4. 异常兜底

| 现场情况 | 处理方式 |
|---|---|
| 没有真实 API Key | 继续使用 Mock + 本地 Demo API |
| Demo API 预检失败 | 直接点击“一键体验 Mock”，展示离线主路径 |
| 页面加载慢 | 等待 backend healthy 后刷新页面 |
| Excel 文件不方便准备 | 只展示输入区域和字段校验说明 |
| 需要展示真实 AI | 明确说明本次不具备真实商业 AI 条件，不现场伪造真实调用 |
| 网络断开 | Mock 主路径仍可运行 |

## 5. 演示完成判定

- [ ] 页面可打开；
- [ ] Mock 报告生成成功；
- [ ] Demo API 预检成功；
- [ ] 样品可载入；
- [ ] 摘要、证据、风险、行动均可定位；
- [ ] 两类图表可见；
- [ ] 商业决策门禁保持关闭；
- [ ] 能说明真实 AI 和真实商品数据的边界。
