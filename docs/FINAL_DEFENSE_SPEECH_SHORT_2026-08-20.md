# 电商选品研判台：演示视频精简演讲稿

> 建议时长：约 2—3 分钟。顺序固定为：技术栈 → 创新点 → 真实演示 → 未来展望。

## 一、技术栈

大家好，下面演示的是“电商选品研判台”。这是基于 DeerFlow 二次开发的 AI 电商选品研究工作台，采用前后端分离架构。

后端使用 Python、FastAPI 和 Pydantic，核心是基于 LangGraph 的 Agent 工作流。系统不是让一个模型一次性生成答案，而是把研究任务拆成八个职责明确的 Agent：Supervisor Agent 负责拆解任务和统一调度；市场 Agent 负责分析市场趋势；竞品 Agent 负责整理竞争格局；价格 Agent 负责价格带和价格分布；用户 Agent 负责目标人群匹配；风险 Agent 负责识别进入壁垒和风险；报告 Agent 负责汇总结构化结论；审校 Agent 负责检查证据、格式和风险门禁。

它们按照“Supervisor → 市场、竞品、价格、用户、风险 → 报告 → 审校”的顺序运行。每个 Agent 产生的中间结果都会进入统一证据池，供后续 Agent 引用，最终形成可追溯的完整报告。

前端使用 Next.js、React、TypeScript、Tailwind 和 Radix UI；系统使用 SQLite 保存历史任务和报告，并支持 Docker、Docker Compose 一键运行。

在能力接入上，系统支持用户自配置 DeepSeek 等模型，使用 Tavily 获取搜索信息，也预留商品 API 和 Excel、CSV、TSV 数据接入。知识库使用向量召回和词法重排，为后续研究提供历史资料和上下文。

## 二、创新点

本产品的核心创新不是简单生成一份商品推荐，而是用 Agent 工作流和工程化规则约束 AI 的不确定性。

第一，Agent 分工让研究过程可解释。用户看到的不只是最终答案，还能知道市场、竞品、价格、客群和风险分别由哪个 Agent 分析，以及这些分析如何汇总成最终结论。

第二，报告固定输出五个板块：市场概况、竞争格局、价格带分析、目标人群匹配，以及风险与进入壁垒。每条关键结论都尽量挂载证据来源，并区分事实、推断和待验证信息。

第三，系统增加了质量门禁。数据不足或使用 Mock 演示数据时，报告会标记为 `DEMO_ONLY` 和 `validate_first`，自动生成验证动作清单，阻止未经核验的结论直接变成采购或放量建议。

第四，项目建立了可度量的评测体系。我们使用 50 条评测集和 LLM-as-judge 做质量评估，并用真实模型裁判发现早期规则评分虚高约 21 分、排序相关性只有 0.085，随后切换了评测口径。这说明系统不仅能生成结果，也能检验自己的结果是否可信。

## 三、真实演示

现在进入实际操作。

我在首页输入研究品类、预算区间和目标人群，例如“宠物智能喂食器”、预算范围以及一二线城市年轻养宠人群，然后选择 Mock 模式并进行能力预检。

本次演示使用 Mock，是为了保证视频过程稳定，不依赖外部网络和 API 密钥。预检通过后，点击开始研究，页面会展示八个 Agent 的实时状态：先由 Supervisor 拆解任务，再依次完成市场、竞品、价格、用户和风险分析，之后由报告 Agent 汇总，最后交给审校 Agent 检查。

这条工作流的关键是“前一个 Agent 的结构化结果成为后一个 Agent 的输入”，而不是多个 Agent 各自输出、最后简单拼接。某个 Agent 发生问题时，系统会隔离该节点、保留已有结果并显示降级原因，而不是让整份报告失效。

研究完成后，可以看到五大报告板块、趋势图、价格分布图、证据来源和验证动作。对于销量、库存、成本等没有授权数据支持的内容，系统不会直接编造，而是明确提示“需要补充”，并要求先完成验证。

用户还可以上传自己的 Excel、CSV 或 TSV 商品表，系统会自动预览字段、完成字段映射和数据校验，再把通过校验的数据纳入研究。报告完成后，可以导出 JSON、Markdown 或 HTML，并在历史记录中回放和比较。

产品说明书中记录的 Live 实验已经完成 12 个真实品类研究，平均每份报告引用 16.9 条真实证据、覆盖 89 个来源域名，中位生成耗时为 46.3 秒。现场演示则优先使用 Mock，确保完整流程可复现。

## 四、未来展望

下一阶段首先接入有授权的电商平台商品 API，用真实价格、销量和库存数据补齐当前竞品分析的短板。

随后引入 OIDC/JWKS 身份体系，将 SQLite 平滑迁移到 PostgreSQL，并通过行级安全支持多用户和多租户；同时用真正的语义向量模型替换当前的基础检索方案，提升知识库召回质量。

最终，产品希望从一个可演示的选品研究工具，发展为中小商家的“选品外脑”，通过按次或订阅方式提供可追溯、可验证的研究服务。

谢谢观看。

## 一句话收束

电商选品研判台不是替用户拍板的自动推荐器，而是一个把 AI 研究、证据追溯、风险门禁和验证动作连接起来的选品决策辅助系统。

## 口径提醒

- 视频主路径使用 Mock，保证演示稳定，不把演示数据描述为真实商业事实。
- DeepSeek 负责模型能力，不等于真实商品数据来源。
- 真实价格、销量和库存必须来自用户有权使用的商品 API 或自有数据文件。
