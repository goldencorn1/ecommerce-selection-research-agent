# 选品研判台：最终产品说明书

版本：Final V1.0
适用对象：演示人员、评审人员、项目交接人员和后续使用者

## 1. 一句话介绍

选品研判台帮助用户把“我想研究一个品类”转化为“我应该先验证哪些方向、证据是什么、风险在哪里、下一步怎么做”。

## 2. 产品输出是什么

一次研究会输出：

- 当前决策建议；
- 推荐方向和综合评分；
- 需求、竞争、价格、客群和风险信息；
- 候选证据及来源边界；
- 价格依据和价格分布；
- 推荐评分趋势；
- 质量门禁和阻断原因；
- 下一步验证动作和失败处理。

产品输出的是验证优先级，不是采购命令。

## 3. 页面结构

```text
顶部演示边界
  ↓
研究配置
  ├─ 品类、市场、客群、价格
  ├─ Mock/Live、模型和搜索配置
  ├─ 商品 API 模板、启用、预检和样品载入
  └─ Excel/CSV 私有数据输入
  ↓
真实能力状态与运行按钮
  ↓
报告区
  ├─ 摘要
  ├─ 证据
  ├─ 风险
  └─ 行动
  ↓
历史回放、对比与导出
```

## 4. 关键交互说明

### 4.1 Mock 演示

Mock 是默认推荐入口，不需要 Key，不调用外部服务。点击“一键体验 Mock”即可生成完整报告，适合现场展示和无网络环境。

### 4.2 商品 API 模板

选择模板只会填入表单，不会自动发送请求。用户需要：

1. 选择模板；
2. 检查 Endpoint、认证方式和字段映射；
3. 勾选“启用”；
4. 点击“预检并读取样品”；
5. 确认样品后点击“载入本次研究”。

本地 Demo 模板不需要真实商品 API Key，适合演示完整交互链路。

### 4.3 报告四段导航

- 摘要：先看结论、平均分和决策状态；
- 证据：查看候选商品、来源和证据边界；
- 风险：查看质量门禁、阻断原因和商业核验状态；
- 行动：查看验证卡片、成功阈值、需补数据和失败处理。

### 4.4 图表

- 趋势图：比较各推荐方向的综合评分；
- 价格分布图：查看价格锚点集中在哪些价格带。

图表仅对当前报告中的候选证据做可视化，不代表真实市场统计。

### 4.5 Excel/CSV

Excel/CSV 适合导入用户自己的商品候选表、供应商资料和核验记录。系统会先预览和校验，不会因为上传文件就自动打开商业决策门禁。

## 5. 状态含义

| 状态 | 含义 |
|---|---|
| 已配置 | 配置项存在，但不一定已连接成功 |
| 可用 | 最小预检已经成功 |
| 已降级 | 系统保留结果，但能力未完整工作 |
| 证据可用 | 证据满足当前质量门槛 |
| 商业决策未就绪 | 仍缺真实销量、成本、库存、合规或人工核验 |
| DEMO_ONLY | 仅用于演示的固定样品 |

## 6. 推荐使用方式

没有真实商业 AI 或商品 API 时：

1. 使用 `start_ecommerce_mock.bat`；
2. 选择“本地 Demo 商品 API”；
3. 启用并预检样品；
4. 点击“一键体验 Mock”；
5. 按“摘要—证据—风险—行动”顺序讲解报告；
6. 最后展示 Excel 输入和导出能力。

## 7. 真实能力说明

DeepSeek 只负责模型分析、总结和报告表达，不提供真实商品销量、库存或排名。Tavily 等搜索服务只提供候选搜索结果，也不自动等于商业事实。真实商品信息必须来自用户有权使用的商品 API、Reader 服务或自有 Excel/CSV 文件。

## 8. 已知限制

- 当前默认演示使用 Mock；
- Demo 商品 API 不是真实商业数据；
- 真实 API 的网络、权限、额度和数据质量由用户负责；
- 当前版本适合本地演示和项目验收，不等同于生产 SaaS；
- 商业采购前仍需人工核验和小批量验证。
